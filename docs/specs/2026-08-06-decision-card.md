# 个股决策卡（五模型拆解）

2026-08-06。张楚寒新一轮反馈：个股页第一屏从「观察卡」升级成「决策卡」。

## 反馈原文的四条要求

1. **最上面直接给明确结论**，从固定枚举里选：逻辑明显增强 / 逻辑小幅增强 / 暂无实质变化 /
   多空证据冲突 / 逻辑出现削弱 / 核心逻辑可能被破坏 / 数据不足无法判断。
2. **拆成几个模型，不能混成一句话**，每个模型能点开看依据；给「模型一致性 N/5」。
3. **给「条件完成度 4/7」，不给买卖点**；条件由用户自设，系统只报满足了几项。
4. 硬规则：没有来源不得生成关系；只有概念关系不得写直接受益；**模型冲突必须展示**；
   **数据不足必须允许不下判断**；每个结论都能点回证据。

> 最终建议：解牛不给交易命令，但会明确告诉用户当前逻辑偏正面还是偏负面、条件完成了多少、
> 什么正在改善、什么仍然不成立。

## 落地

- `src/lib/decision-card.ts` — 纯函数、零 AI 的五模型引擎（29 条单测）。
- `src/app/entity/[id]/decision-card.tsx` — UI，竖排 `<details>`，服务端组件零 JS。

  日线 / 结构化事件 / 一致预期 / 解禁 / 融资。并进个股页那**唯一一个** `Promise.all`。
- 替代 `lib/watch-status.ts` + `entity/[id]/watch-card.tsx`（已删）。

## 五个模型吃的是五个**不同**的数据源

切同一池信号五刀会造出假的多样性——五个模型永远同向、一致性天天 5/5，等于没有信息。
第一版就踩了：基本面和事件并排显示了同样三条回购证据。现在按**维度族**互斥拆开。

| 模型 | 数据源 | 窗口 | 能投什么票 |
|---|---|---|---|
| 基本面 | 打到**经营族**维度的信号 + 最近一次**一手**业绩披露 | 90 天 | 改善 / 走弱 / 未变化 / 待确认 |
| 估值与预期 | `EntitySignal.consensus`（覆盖家数 / 评级分布 / 两年 EPS） | 快照 | **只投反对或弃权**，见下 |
| 事件 | **治理/外部/预期族**维度的信号 + 一手结构化事件 | 30 天 | 改善 / 走弱 / 未变化 |
| 趋势与资金 | `MarketDaily`：涨跌幅链 + 主力净额（三票制） | 20/60 日 | 改善 / 走弱 / 未变化 / 待确认 |
| 风险 | 解禁 / 融资余额 / 需复核体裁公告 / 偏恶化信号 | 90 天 | **只投反对或弃权** |

两个「只往下投票」的模型是刻意的：

- **估值与预期**：全库 798 份一致预期里，次年 EPS 增速中位数 **+33%**、p75 **+96%**，
  「≥15%」占 **68%**——「机构预期高增」在 A 股是默认档，没有鉴别力。拿它当支持票等于
  给三分之二的卡凭空加一分。真正有信息量的是**下滑**那 7%。而「上修还是下修」这个本该
  最有用的判断做不了：库里只有一致预期的**当前快照**，没有历史。这句写在卡里。
- **风险**：没有风险 ≠ 利好。把「暂未发现风险」记成支持票，会让冷门股拿到一票凭空的正面。

## 结论枚举的判定顺序

```
unknown ≥ 3                                  → 数据不足，无法判断
顶档(materiality≥80) 一手反面证据 + 基本面与风险同时走弱 → 核心逻辑可能被破坏
support ≥1 且 against ≥1 且 |net| ≤ 1         → 多空证据冲突
net ≤ -2 或（against ≥1 且 support = 0）      → 逻辑出现削弱
net ≥ 3                                      → 逻辑明显增强
net ≥ 1                                      → 逻辑小幅增强
否则                                          → 暂无实质变化
```

「冲突」刻意**不**被平均掉：两侧都有读数时直接出冲突，并在标题里点名是哪两个模型在打架。

## 条件完成度

条目**全部**来自用户自己：未静音的维度 + 到价观察位，解牛一条都不添。
- 满足 = 该维度近 90 天有过该维度敏感度门槛的 bull 证据；
- 出现反面证据 = 有 bear（**优先于满足**显示，同一维度上先给用户看坏消息）；
- 待满足 = 没有达标事实；
- 「近 7 天新满足 N 项」代替反馈里的「比昨日增加 2 项」——库里没有每日快照，
  但「支撑这条的证据是哪天发的」是现成的，同样能回答「比上次多了几项」。

## 没做：历史相似状态

反馈第 4 条（「过去 5 年出现过 18 次相似状态，未来 20 个交易日上涨 11 次…」）**没做**。
`MarketDaily` 每只股最多 **143 根**日线（约 7 个月），连一个完整年度周期都不够。
用 3 个样本冒充统计正是这份反馈自己反对的「把错误包装得更可信」。
要做，先把日线回填到 5 年（约 1200 根/只 × 5.3k 只）。

## 真实数据冒烟（41 条自选行，2026-08-06）

```
结论分布   多空证据冲突 17 / 暂无实质变化 10 / 逻辑出现削弱 7 / 小幅增强 6 / 明显增强 1
基本面     改善 15 / 有单条改善 7 / 暂无改变 8 / 数据不足 10 / 走弱 1
趋势与资金 方向不明确 19 / 正在走弱 13 / 正在强化 7 / 数据不足 2
风险       偏高 18 / 中性 12 / 暂未发现 5 / 中高 3 / 数据不足 3
条件完成度 0/5 有 15 份，其余 1/5 ~ 3/6
```

冒烟抓出来、只有真实数据才会暴露的四个问题（都已修）：

1. 「最近一次业绩类披露」指向了一篇被打上「财报」体裁的**媒体综述**（「月内超 600 家 A 股
   上市公司获机构调研」）→ 该锚点只认 `tier=PRIMARY`。
2. 同一次回购的三条追更被当成三份证据并排显示 → 每个维度只留最强的一条
   （同一件事靠**主体收口**，不靠标题近重复——措辞和数字都不一样，字符串比对拦不住）。
3. 「最重要的新增证据」显示的是「公司回购金额较大，显示现金流状况良好」这种形容词，
   而同批信号里有「累计回购 70.5 万股、支付 1.44 亿元」→ 排序加一档「带数字的优先」。
4. 「大宗交易：1 笔共 608 万元，均溢价 0%」曾占据「现在发生了什么」的头条 →
   微结构体裁（大宗交易/龙虎榜/融资融券/股价异动）计数照算但不进展示。

## 遗留的**数据层**问题（不是这张卡的 bug）

- **事件模型 31/41 是「未触及命题」**：`ThesisSignal` 的维度绝大多数落在经营族
  （`dimensionFamily` 对认不出的 key 兜底成 operating），治理/外部族很薄。
  这正是反馈里说的「前面 80% 的事实与关系底座」——要让事件模型活起来，
  得先让维度词表和实体关系覆盖到股权/政策这一层。
- **信号方向严重偏多**：近 30 天 bull 354 / neutral 48 / bear 34（87% 偏多）。
  于是「改善」是默认档、「核心逻辑可能被破坏」在 41 个样本里 **0 次触发**。
  这是分类器的偏置，不是卡的判据松——判据本身有单测钉住能触发。
- **一致预期只有快照没有历史**：无法判断上修/下修，估值模型因此不投正面票。
  存一张 `ConsensusHistory` 就能解锁「机构预期正在上修」这个真正有用的读数。
